01

按钮体系

先定层级，再定尺寸。主操作每屏最多一个，其余全部降级。

主操作实心 · 32px

提交、应用、发送。一屏只出现一个，其余动作使用次级样式。

次操作描边 · 28/32px

工具条与表单里的常规动作；浮层底部统一「恢复默认 · 取消 · 应用」。

工具按钮图标 · 24px

只用图标时必须带 title / aria-label；同类工具放同一组，组与组之间用 1px 分隔线。

选择器分段 · 28px

互斥选项一律用分段，不用多个勾选框；选中态只在段内出现，不叠加边框。

开关 / 单选持续状态
自适应高度 显示均量线

持续开启的偏好用开关；互斥的一次性模式用分段或单选按钮，不要混用按钮 + 复选框。

自选入口

收藏不只是一个心形：要让人一眼看出「已收藏 / 在哪些分组 / 怎么改」。

已选：默认 / 趋势

点分组即加入 / 移出 · 一只股票可属于多个分组

心形 + 下拉小角 = 可展开；点击直接出分组浮层，不再跳全屏弹窗。未收藏时浮层提示「点分组即加入」。

分组胶囊

自选页 / 右卡

默认单选；需要多选时按住 ⌘ / Ctrl。提示写在胶囊 title 里，并在右上角常显一条操作说明，避免「点了没反应」。

批量与撤销

统一动作

加自选后 toast 带「撤销」；移出只在浮层或管理面板里出现，不在主信息条放第二个删除入口。

现状问题
  • 心形无文字、无 caret 时，新用户不知道点开能选分组。
  • 分组单选 / 多选规则只藏在 title 里，触屏与新手无从得知。
  • 加入自选后 toast 无法撤销，误触只能再点一次移出。
优化决策
  • 心形固定带 caret，已收藏用强调色底；悬停显示「分组 3」小徽标。
  • 浮层顶部常显「已选：默认 / 趋势」，分组行用勾选态。
  • toast 增加「撤销」，2.5 秒内可回滚。

指标与设置

方案是「一套组合」，设置是「单个指标的参数」，两层分开，不再混在一个齿轮里。

指标方案

一键切换标准
通道配色
切换只影响线条色，不影响指标计算
现状问题
  • 方案、常显指标、参数设置是三个独立浮层，入口图标还不一样。
  • MA 7 条全显，周期重复时线条叠在一起也没有提示。
  • 设置浮层按按钮定位，展开后遮挡图例与右上角报价。
优化决策
  • 方案 → 组合；设置 → 参数，两层放在同一张卡里，tab 切换。
  • 默认只显示 3 条 MA；重复周期实时提示「会重合成一条」。
  • 浮层统一锚定面板右上角，宽 280，最大高 60vh，内部滚动。

DEPTH盘口 6 项优化

  1. 概念可展开：默认只露 5 个，hover 或点「+N 更多」弹出全部，浮层固定定位，不被卡片裁切。
  2. 名称同色 + 箭头：名称、现价、涨跌同一颜色；三角箭头带一次性入场动画，替代静态文字。
  3. 两融标识：融资融券（橙）/ 非两融（灰），hover 提示「支持融资买入」。
  4. 关键字段分组：简洁档只留 8 项（最高/开盘/最低/昨收/振幅/涨跌停/量比），详细档补全 18 项。
  5. 五档对齐：档位 / 价格 / 手数 / 金额四列等宽，量条从右向左生长，买卖两侧用淡色区分。
  6. 委比条：红绿双向比例条 + 委比 / 委差数字，一屏判断买卖压力。

RULE全部卡片统一规范

  1. 卡头 34px、body 10px 内距；数字一律等宽、右对齐。
  2. 默认档位：盘口 / 成交明细 详细，其余 简洁；每卡独立记忆。
  3. 轮询只替换 .fbody，不重绘整列，不闪、不丢滚动位置。
  4. 空态固定文案：指数盘口「暂无五档盘口」、非交易时段「暂无逐笔成交」。
  5. 卡片顺序可拖拽，和设置面板共用同一份 order。

  • 侧栏拖拽 48–220px 并记忆；图标 40px 居中，tooltip 右侧浮出。
  • 移动端固定 5 项页签（行情/自选/目标/智能/设置）。
  • 全局 ⌘K 聚焦搜索，Esc 关闭所有浮层。

  • 分页器含首页/上页/页码/每页 20·50·100·200/下页/尾页，条数写入本地。
  • 空/载入/失败三态保留表头与列宽，失败给重试。

  • 减弱动效时关闭箭头/骨架动画，只保留状态切换。
