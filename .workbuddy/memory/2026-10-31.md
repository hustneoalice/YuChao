## 资金流卡片重设计（用户反馈「信息乱、不规整」）
- 口径修正：原先四档颜色被写死（超大/大单恒红、中/小单恒绿），方向与正负无关；现改为**按符号上色**——净流入（正）红 `--up`、净流出（负）绿 `--down`、±50 万内中性。
- 视觉语言统一为一套「大字 + 零轴双向条」：`mf-hd/mf-lead/mf-v`（22px 主力净额，单位小一号）、`mf-rows`（`display:contents` 摊平成三列网格：40px 标签 / 1fr 轨道 / max-content 数值，跨行严格对齐）、`mf-track`（居中零轴，左绿右红，半幅 50% 归一，非零极小档保底 1.5%）。
- 当日卡新增「占成交额 = 主力净额 / 当日成交额」（流入强度），右侧 meta 显示日期；无资金流（指数）改为「今日成交额 + 原因 + 框选提示」，日期只取 `date.slice(0,10)`（指数 quote.date 带时分）。
- 区间卡重排：涨跌大字 + 右侧振幅/阳阴 → 最高/最低/成交额/日均两列键值 → 分隔线 → 区间主力净流入 + 四档条；删掉原先 6 行空 `.mbt` 假进度条（正是「看着乱」的根因）。
- 简版两行：`mf-line`（数值 + 占比）+ 右侧 `mf-stack` 四档堆叠条；`fmt.ts` 新增 `fmtYiS`（带符号亿/万亿，小于半个显示单位不出 "-0.00亿"）。
- 清理：删除 `mbar()` 与 `.flowbars/.mbar` 无用样式（`.mbl` 仍被指标/估值卡使用）。tsc + build 通过，playwright 复核个股/混合正负/指数/区间/简版/亮色主题。

## 点击单根 K 线 → 资金卡切「单日态」
- 交互：点任意一根 K 线（按 x 列命中，不要求点中蜡烛实体；v10 原生 `onCandleBarClick` 只认实体矩形，间隙点不中，故改用 mousedown→mouseup 位移 <5px + `convertFromPixel` 判列）。再点另一根即切换；点未来空白区 / 卡上 ✕ / 换标的 / 切周期都会撤选中。
- 图上反馈：`.kl-pick` 竖向高亮带（宽=barSpace，顶部日期徽标），跟随滚动/缩放重绘（订阅 onVisibleRangeChange / onZoom / onScroll）。
- 唯一真相是**日期**不是索引：盘中 12s 轮询重灌数据索引会漂，drawPick 每次按 date 重新定位；数据里找不到该日期就隐藏。
- 与框选互斥：`yc:kl-pick` ↔ `yc:kl-range` 互清（右卡同时只表达一个口径），框选模式下短点击也补一次单根选中。
- 卡片：`moneyflowPickBody()` 与区间态共用视觉语言（rg-head/mf-hd/rg-kv2/flowRows）——单日 tag + 日期 + ✕ / 日涨跌大字 + 振幅·收 / 开·昨收·成交额·量 / 主力净流入 + 占成交额 + 四档条。分时/60 分（date 含时间）不拉接口，只提示「按日口径」。
- 数据陷阱：新浪 capital_flow 部分交易日只回 net_main、四档全 0（例 600519 2026-10-22）。新增 `flowDetailOk()`（四档和与主力差 >30% 判为不可信）→ 显示「分档明细缺失」替代一排 0.00亿，当日/区间/单日三处共用。缺失日 amount 也常为空 → 成交额显 "—"。
- 顺带修：setData 增加 keepView（market 侧按 `symbol|period` 判是否增量刷新）。原先盘中每 12s 重灌都把视图弹回最新，翻历史必被打断。恢复用 `scrollToDataIndex(to-1)`（v10 该 API 是把索引对到视口**右端**，传 from 会整整错开一页），并加两道守卫：旧范围超界 or 新老长度差 >15%（日线 2000 → 分时 267）一律回最新。
