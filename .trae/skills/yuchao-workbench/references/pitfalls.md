# 踩坑清单 · 症状 → 根因 → 对策

从 1.0（strategy-lens）实盘运行 + 2.0（驭潮）重建过程中真实踩过的坑。
每条都值得一段回归测试——「所有新增的可靠性机制必须配套覆盖真实故障场景的测试用例」是硬约定。

## 一、数据获取（采集层）

1. **切股延迟 8 秒+**
   - 症状：K线页切换股票后顶部信息条迟迟不刷新。
   - 根因：东财 push2 实时快照接口 keep-alive 时间短、频繁连接超时。
   - 对策：腾讯批量 GBK 接口做主车道（`fetch_qt_batch`，≤50 只/次，毫秒级），
     东财快照兜底 + 10 秒缓存；快照有盘中有效数据时覆盖价/涨跌/量/额字段。

2. **「网络失败」其实是参数错**
   - 症状：某车道全部返回空，被误判为上游故障触发熔断。
   - 根因：车道间 symbol 格式不同（裸代码 / sh600xxx / sz000001 / gpsh600xxx），
     直接透传裸代码上游返回空。
   - 对策：所有车道统一走 `http.py` 的 `market_prefix / tx_symbol / sina_symbol /
     suffixed_symbol / pure_of` 转换函数，禁止手写前缀拼接。

3. **WAF 假成功**
   - 症状：任务报成功但库内数据是截断/整包垃圾（曾实测「估值只写入 37 行」）。
   - 根因：被 WAF 软拦截时 HTTP 仍返回 200，body 是伪装页或空壳。
   - 对策：多层组合——UA 池随机、指数退避、伪装页特征检测、域名轮换
     （`http.py get_json_hosts`）+ registry 声明 `min_rows` 写后行数下限，
     低于下限按失败处理进自动重试。

4. **100 倍量纲脏数据**
   - 症状：成交量/成交额偶发放大 100 倍，指标全部失真。
   - 根因：不同源单位不统一（手/股、元/千元），个别源改版未公告。
   - 对策：`normalize.py _selfcheck_volume` 单位自证纠偏——用
     隐含均价 = 成交额 ÷ 成交量 与收盘价比对，偏离量级即纠偏或拒收。

5. **空壳/浅数据/OHLC 非法落库**
   - 症状：K线出现 high < low、成交量恒 0 的残根。
   - 对策：`normalize.py guard_rows` 写前深校验，非法行拒收并计数上报。

6. **数据静默断供（最隐蔽）**
   - 症状：全市场日线长期缺增量，但日志里没有明显报错；熔断后仅靠盘中实时
     合并补出「残根」。
   - 根因：主车道采集函数缺失局部 import，异常在 except 里被吞。
   - 对策：采集函数依赖必须完整导入；新增车道后先 mock 断网跑一遍失败路径。

7. **采集空转 2 小时**
   - 症状：上游整体不可用，任务挂着不动、进度 0%。
   - 对策：连续 40 只失败早停 + 车道级熔断（连续 3 次失败冷却 300 秒并切换
     下一车道）+ 冷却到期先半开探测（单标的试探）成功后再满血。

8. **依赖 = 纯 cron 时间错开**
   - 症状：复权因子周六失败，下周 K 线照常硬算。
   - 根因：调度只管时间不管上游健康。
   - 对策：registry 声明 `needs`，上游当日 update_log 有 failed 账 → 下游自动 skip。

## 二、更新体系（编排层）

9. **API 全灭**
   - 症状：采集期间前端整站打不开，无默认行情。
   - 根因：DuckDB 写连接排他，长任务全程持锁，只读连接全部被拒。
   - 对策：锁只在任务执行窗口持有，分批写、批间 `writer.reset()` 让位；
     空闲期绝不持锁。

10. **写锁耗尽 → 增量更新永久失败**
    - 症状：150 秒后 updater 的所有外部请求开始重试死循环。
    - 根因：updater 内 API 调用用线程缓存连接 + 空闲收割器，叠加前端 3s 轮询，
      连接池被读锁占满。
    - 对策：updater 进程内一律 per-request 开关连接。

11. **队列冻死**
    - 症状：一行落账异常后所有排队任务永远不执行，writer.reset() 被跳过。
    - 根因：worker 线程 unprotected，单次异常终止整个消费循环。
    - 对策：落账/回调只告警不外抛，单任务失败与队列存续隔离。

12. **失败即终局**
    - 症状：一次源超时 = 当天没数据，只能次日 cron 碰运气。
    - 对策：终态失败当日退避重试 2 次（5/15 分钟）；manual 触发与用户取消不重试；
      重试计时器不落盘，进程重启漏跑由次日 selfheal 兜底（分层容错）。

13. **新鲜度不前置**
    - 症状：节假日/已更新日任务照跑，浪费源配额、放大被 WAF 风险。
    - 对策：`_precheck` 前置 freshness 两模式——表日期比对 / update_log 账本校验，
      已新即 `skipped(fresh)` 秒跳（是信息不是错误，落账 level=info）；
      force 参数可越过。增量型任务（K线/资金流）不声明——重跑=补缺口，不能拦。

14. **幽灵交易日**
    - 症状：holidays 依赖包过期后 fail-open，把假期当交易日跑任务。
    - 对策：`trading_calendar.calendar_health()` 断言日历覆盖当年+次年，
      未覆盖/未安装 → degraded/stale，进 audit 体检第 6 项显式报警；
      日历必须是独立前置锚点，禁止从数据表内容反推（循环依赖会随数据停摆）。

15. **零备份 / 备份不可信**
    - 症状：库损坏无回滚点；或热拷贝副本两次审计结果互相矛盾。
    - 根因：热拷贝读到半写页。
    - 对策：每日 18:10 任务先 CHECKPOINT 再 copy2，副本 read_only 挂载
      数表校验可读，滚动保留 7 份；审计脚本遇锁冲突提示停服，禁用副本降级。

## 三、界面与前端

16. **klinecharts v10 画布空白且无任何报错**
    - 根因：v10 dataLoader 门控——`setSymbol`/`setPeriod` 未显式配置前
      `getBars` 根本不触发。
    - 对策：初始化顺序固定为先配 symbol/period 再喂数据。

17. **最新 K 线不贴 Y 轴**
    - 根因：klinecharts 默认 offsetRightDistance 50px。
    - 对策：显式设 0。

18. **前端字段悄悄缺失**
    - 症状：后端明明返回了，前端拿不到。
    - 根因：pydantic response_model 静默过滤未声明字段。
    - 对策：契约加字段必须同步 response schema；改完跑 `gen_ts_client.sh`。

19. **[hidden] 元素意外显示**
    - 根因：CSS `display:flex` 特异性压过 HTML hidden 属性。
    - 对策：全局 `[hidden]{display:none!important}`。

20. **下拉点击失效**
    - 根因：innerHTML 重渲染把监听器连同 DOM 一起换掉。
    - 对策：事件委托 + 定点 span 插入，不整块重绘。

21. **显示的是昨日收盘价**
    - 根因：SSE 只通知「采集完成」不落数据，前端等不到快照。
    - 对策：实时价合并三护栏——TTL 统一时效、开盘前假 bar 日期守卫、
      量单位换算统一；前端 10-15s 轮询只刷最后一根 bar，不整表重载。

22. **主题/色值失控**
    - 对策：三层 token（L1 原始色板 → L2 语义变量 --bg-page/--accent/--up/--down
      → L3 组件），涨跌色方向可切换（红涨绿跌为默认）；组件层禁止硬编码色值。

23. **用户偏好被旧值覆盖**
    - 根因：防抖计时器未触发时刷新页面，服务端旧值回写。
    - 对策：beforeunload/visibilitychange 触发 keepalive fetch 立即冲刷。

24. **自研指标把 UI 配色逻辑搞挂**
    - 症状：成交量柱涨跌颜色判断失效。
    - 根因：指标 calc 返回结果缺开盘价/收盘价原始字段。
    - 对策：自研指标 calc 返回项必须带完整 OHLC 原始字段。

## 四、架构与工程

25. **schema 漂移**：新表/加列只在代码里改 → 老用户库崩。
    对策：三路分发（NEW_TABLES_DDL / MIGRATIONS 幂等 / conftest 镜像），
    ensure_schema.py 与 packaging.import 换库后重建全链路兜底。

26. **快慢变量同表**：财务（报告期级）混估值（交易日级）→ 冗余、链路冲突、表膨胀。
    对策：分表存储。

27. **契约没先行**：前端猜字段 → 联调返工。
    对策：contracts → router → gen_ts_client.sh → 前端只 import yuchao.d.ts。

28. **多进程 seq 乱序**：SSE 跨进程广播序号回退。
    对策：Redis backplane 用 INCR 保证跨进程单调；缺省文件总线零依赖。
    EventSource 不支持自定义头 → license 频道用 `?token=` 传身份。

29. **配置逻辑散落**：守卫参数写死在代码各处。
    对策：全部 registry 声明注册，embedded 层透传。

30. **一码多用/越权**：激活码并发兑换被复用；VIP 过期仍见数据。
    对策：激活码原子 UPDATE...RETURNING 一码一用；tier 实时判定，
    JWT 只是快照，过期即刻 403 不返回数据（服务端脱敏）。
