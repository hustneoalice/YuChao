## 内部结构计算继续追踪

以下针对已确认 SYS_DLL2 的 `Dll_chanlun_zycft.dll`，为静态控制流推导，尚未用 DLL 输出样本逐点验证。

### 输入字段与计算顺序

包装函数将五个输入依次存于对象 +0x40(H)、+0x44(O)、+0x48(L)、+0x4c(C)、+0x50(V或参数N/M)，长度 +0x54。

- ID1：`0x1000a140` 清零 +0x24 的向量，再调用候选提取 `0x1000adb0` 和端点整理 `0x1000b2d0`。
- ID9：先运行同一基础计算，随后取第五个数组的首项作为参数（`0x1001e803`），传入 `0x10016790`。该函数从基础 +0x24 向量出发，经 `0x10016b50` 得到 +0x2ac 向量，再经过端点整理及计数 `0x1000a200`。
- ID17：类似路径使用 `0x10016840`，同样从基础 +0x24 向量出发、调用 `0x10016b50`，结果存 +0x2b8。并非直接以 ID9 输出再递归计算；调用顺序和数据地址已确认。
- ID3/4 在基础计算之后走同一个双输出计算 `0x1000a190`；ID11/12、19/20 分别增加对应层级计算及 `0x10017400`。信号枚举含义尚未恢复。

### 已读清的端点整理规则：0x1000b2d0

从索引3扫描到 length-2，只处理输出值 > 0 的位置，判断它是否等于当日 H 或 L。维护已遇到的非零点序号，以及上一次高点/低点的序号和索引：

1. 若当前为高点，且它与上一个高点在非零点序列中相邻，则在两个高点索引之间（不含两端）搜索最低 L，将该最低价写到相应历史索引的输出。
2. 若当前为低点，且它与上一个低点在非零点序列中相邻，则在两个低点索引之间（不含两端）搜索最高 H，并回写到该历史索引。
3. 极值比较为严格小于/大于，等价极值保留首次找到的位置；扫描排除最后一根。
4. 此遍历是在输入输出同一向量上原地回写；新增历史点不重新计入当前已走过的序号。不能等价替换为“先插点再整体重扫”。

边界初始化包含序号=1、索引=0及最高/最低哨兵；异常数据/NaN语义未转换成独立实现，避免误称完整等价代码。

此规则说明原指标会在后续端点出现后补写早先位置。它对历史图形与实时信号确认时间有不同影响；不能将历史端点日期直接当成实时可见信号日期。完整重绘范围仍需逐根前缀样本验证。

## 首次原 DLL 受控运行验证

已在 Windows 虚拟机独立 32 位 PowerShell 进程中使用自编 C# harness 调用原 SYS_DLL2。每组独立进程，不附加众赢进程，不修改其配置或行情。原生 ABI：cdecl，`void(int length,float* output,float* H,float* O,float* L,float* C,float* param)`。RegisterThrdFunc 使用六字节编号/指针表。脚本位于 `zhongying-windows/probe-chan.ps1`。

加载依赖核对：结构 DLL 导入 MSVCP120.dll、MSVCR120.dll，需从 allwin 安装根目录预加载；信号 DLL 则依赖 MSVCP140.dll、VCRUNTIME140.dll。最初 error126 的加载失败未计为计算结果；最终调用均返回且输出文件落盘。加载成功后 GetLastWin32Error 可能是旧值，非零句柄才是成功依据。

人工输入：C[i]=float32(100+10*sin(i*pi/10)+0.05*i)，O=C，H=C+1，L=C-1，第五数组填指定参数。没有真实股票数据。

验证结论与边界：

- ID1 的40根输出与80根输出前40项完全一致；本例未观察到历史回写，不能外推所有波形。
- N从4改为16显著过滤端点，符合静态代码的间距筛选路径；不能简化成唯一的最小间距条件，因为存在价差/状态分支。
- ID9和ID17在参数同为16时80项完全一致，结合先前同一内部筛选函数的数据流证据，支持二者是同一基础结构的不同参数层，而不是必然递归的笔/线段关系。尚未证明对任意输入均相等。
- ID9(N4)保留到索引65，没有ID1在75的最后低点；层级过滤存在尾端处理差异，不能照搬基础层最后端点。
- `0x10016c2e..0x10016c59` 显示一条高点分支的有效间距为 `i-anchor - int(C[i-1]>C[i]) + int(C[anchor]>C[anchor-1])`，转换float后与N比较（>=）。另有分支采用不同anchor，完整状态机尚未还原。

sine与mixed两种波形、参数4/8/16共六对ID9与ID17的80项数组全部相等。mixed端点数随参数4→8→16分别由16→6→3；启动端点存在小于参数间距的例外，不能把算法替代为简单的相邻端点最小间隔。
