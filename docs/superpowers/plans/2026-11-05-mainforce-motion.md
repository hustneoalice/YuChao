# 主力动向试验版实施计划

**Goal:** 独立日期查询页面展示近似力度前50及三因子，不冒充众赢原模型。
**Architecture:** 固定此前20只训练样本拟合的岭回归参数，三个输入log1p(主力净额)、同日占比、当日量/此前20日均量；只读查询历史库，不新增调度或改核心标。复用现有军情router和表格组件。
**Tech Stack:** Python/FastAPI/DuckDB + TypeScript/Vite。
