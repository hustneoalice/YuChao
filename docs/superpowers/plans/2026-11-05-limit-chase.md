# 涨停追击收盘版实施计划

**Goal:** 独立涨停追击入口：涨停个股、连板天梯、强势板块；按真实历史快照计算，不伪造盘中事件。
**Architecture:** 只读market_snapshot（分日留存真实涨停价）、资金表、日线及当前板块成分；repo统一分类/汇总，现有军情router新增读取端点，复用前端表格/分页/日K。不开新采集、ETF补数、定时任务。
**Scope:** 当日/昨日涨停、触板未封、自然/一字、市场/ST、历史日期；精确历史涨停价缺失即未知；连板历史不全标至少N板；强势板块定义为当前成分中至少一只涨停，涨幅标明成分均涨。封单按快照买一（手）*100*涨停价，仅买一价确为涨停价时计算。首次/最终封板时间、最大封单不由日线推测。历史使用当前成分，不是历史成分复原。

- [x] API过滤参数与三模块数据，过去日期只用同日/此前快照→验证无未来回填。
- [x] 三页签、市场/ST/日期/类型、板块周期与成员联动、排序分页、日K跳转、数据覆盖提示→TS/build。
- [x] 定点部署云端，核对已知快照123家样本差异、历史空值、板块及成分；浏览器可用时实测并保存截图，否则明确受限。


## 验证与数据限制

新增涨停追击7项测试、报价日期2项测试均通过；其余模块27项及快照采集2项此前通过，共38项相关检查。本地/云端TS与Vite构建通过。云端按真实UI参数end、markets、show_st、period查询通过：11月4日不含ST119只、触板未封35只、有效样本封板率77.27%，609个含涨停股板块；科创板/5日条件12只、100个板块。长鑫存储3/18及涨停3只与原软件样本一致（北方华创、雅克科技、拓荆科技）。

发现历史快照日期污染：11月3日长电快照51.74实际是11月4日价格，11月3日日线为47.04。修复盘中快照使用expected_asof误将当天报价写到上一已收盘日的路径，同时改用北京时间并校验报价自带日期。未改写旧库记录；查询时对过去日期比对同日原始日线开高低收，冲突/无法核验不作信号。11月3日的5356只筛选快照全部无法核验，已显示数据不足，不显示虚假的0家涨停或100%续板率；连板标≥N板。含ST11月4日确认122只，未强凑原软件123只。公共历史涨停池试取返回rc205、没有记录，未进行回填。

云端IAB新建页面仍在45秒后超时；已阅读浏览器故障指引并尝试新标签，暂无可用UI截图，页签点击和日K跳转尚未实机验证，API核验不替代UI证据。该UI验证步骤受到工具阻塞，其余实现和部署已完成。
