# 十大流通股东实施计划

**Goal:** 在行情右侧展示可切季度的十大流通股东及持股数量变化。

**Architecture:** 新增 foundation/shareholders.py 完成公开数据读取、缓存、季度整理和比较；market 路由返回类型化数据；独立前端 shareholders.ts 渲染并通过原卡片机制接入。

**Tech Stack:** FastAPI / httpx / Pydantic / TypeScript / Vite。

## 约束

仅按需获取单股，缓存一小时；不启动批量更新。不改ETF暂停配置，不覆盖已有改动。股数与金额、报告期与公告日期明确区分。
