# 强势调整：用户约定规则

本设计替代此前误用的「涨停战法」同名条件。属于用户约定候选规则，不声称复现众赢专有算法。

- 涨停：沿用固定C>前收*1.095且H=C；有效正成交量。
- 次根：成交量/涨停量严格大于0.5且严格小于2。
- 后续：量比必须严格大于0.5；任意根<=0.5或缺量立即结束，不恢复。
- 保护位：涨停日最低价，含下影线。最低价跌破保护位结束；等于不结束。
- 新涨停结束旧组并重新起组。
- 存续期间C>=MA45才标记；弱势根跳过而不结束，延续用户仅指定的终止条件。
- 第一根符合条件的涨停次日也可命中，不添加未授权的额外延迟。
- 同组一只眼睛，向全部命中K线最低价画红箭头；绿色保护线从涨停日延至存续末根。
- 眼睛置于首末命中中点；纵向放在保护位下方，按涨停日振幅及价格的4%留空。只为排版，并非原软件公式。新增命中会改变眼睛位置，但不会改写历史命中结果。

验证：50%/200%严格边界、下影线保护、破位终止、新涨停替换、缺量、MA45等值、历史前缀稳定与输入不变。20项测试与生产构建通过。
实际本地前复权行情：002812 2026-04-27/28/29同组命中，保护位69.4701515；2026-02-09命中，02-10因量比0.456322结束，02-11不恢复。与用户二月截图三线不一致是已明确的规则差异，不硬凑。
