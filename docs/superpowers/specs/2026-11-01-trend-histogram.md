# 趋势柱线公式版

用户明确要求继续将趋势柱线接入yuchao，沿用现有副图选择器。仅接入该指标，无买卖提醒。
来源：本机众赢财富通4.1.14 sys_index1.xml的趋势柱线定义。

CHL=(H+L+3*C)/5；动态周期为min(已有根数,5/8/13/21/34/55/89)。各EMA逐根用当前周期递推，首值CHL；MAx=(CHL+Mx*EMA(CHL,Mx))/(Mx+1)。真实波幅经55周期动态均值及34周期动态均值归一化。CFJD0为原式多周期差加权值；CFJD2=MA(CFJD0,15)。CFJD1未参与显示，未计算。

按四条STICKLINE顺序绘制：0→CFJD2按正负红绿；CFJD2→CFJD0按相对大小红绿；保留柱间空隙，并按截图连接CFJD0轮廓。个股及指数均支持，不依赖股本或成交量。

初始化约定：REF首值取当前close，动态MA窗口不足用已有样本，EMA首值CHL；MA15需15个有效样本；零波幅留空。这些公式引擎边界尚未与原软件逐点核对，不声称完全一致。

验证：恒价、涨跌对称、缩放不变、零波动、前缀稳定、动态EMA第6根手算625/378；生产构建；浏览器实际绘制。
