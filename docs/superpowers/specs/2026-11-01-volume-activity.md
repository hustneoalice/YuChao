# 量能活跃公式移植

来源：本机众赢财富通 4.1.14 class.special.index.js 的 i_lnhy。按已确认的副图接入方式继续。未与当前原应用逐点对照。

短线量能 = (MA(换手率,5)-MA(换手率,60))*80000。
趋势量能 = MA(SUM(涨跌方向*换手率*10000,30),10)，平盘贡献为0。
从第61根开始显示；TL 为60周期最大成交量且收盘高于60周期均价；PP 为突破前120周期最高价并满足原式涨幅、均价与加权价过滤；DL 为120周期最低量且非零振幅、不满足PP。从第121根起启用DL。保留原 getB 末项 REF(A,20) 跳过19的行为。PP 优先TL。

成交量单位为股。最近一个有效日（历史缺失时使用当前报价）的成交量*100/换手率反推固定流通股本，整个序列使用该估值。换手率舍入、股本变化与原接口 circcapital 单位未比对可能造成差异。不是逐日使用换手率（原代码亦使用单一 stockSummary）。指数不计算。缺股本、窗口中缺成交量输出空值，不补零。

原脚本把价格转换为字符串后部分关系比较可能采用字符串顺序；移植统一采用数值比较，不承诺复现该潜在缺陷。现有周期聚合口径沿用项目实现。

实现：volume-activity.ts 纯函数；kline.ts 注册红绿柱、蓝线及TL/PP/DL文字；market.ts 传递股本估计。
验证：恒量、放量手算、平盘趋势、PP/TL优先、DL、缺失数据、股本单位、前缀稳定及不变输入；生产构建；个股页面实际检查。
